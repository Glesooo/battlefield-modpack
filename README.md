# M.A.C.E

Сборка Minecraft 1.20.1 Forge для военного PvP-сервера M.A.C.E и её лаунчер.

## Как начать играть

1. Скачайте лаунчер: [MACE.exe](https://github.com/Glesooo/battlefield-modpack/releases/download/pack/MACE.exe).
2. Запустите его. Windows может предупредить о неизвестном издателе: у лаунчера нет платной цифровой подписи.
   Нажмите «Подробнее» → «Выполнить в любом случае». Исходный код лаунчера лежит в этом репозитории.
3. Введите ник и придумайте пароль. Пароль закрепляет ник за вами: без него под вашим ником на сервер
   не зайти.
4. Нажмите «ИГРАТЬ». В первый раз лаунчер скачает игру и сборку, около 1,5 ГБ.
5. В меню игры нажмите «ПОДКЛЮЧИТЬСЯ».

Если раньше вы играли через старый апдейтер или Prism Launcher, при первом запуске лаунчер предложит
перенести управление, свои настройки и шейдеры из прежней папки игры. Позже это можно сделать в
«Настройки» → «Перенести настройки из прежней папки игры…».

## Частые вопросы

**Забыл пароль.** Напишите администратору: он сбросит пароль ника, и следующий вход задаст новый.

**Пишет «Неверный пароль».** Нажмите «Ввести заново» под ником и введите свой пароль.

**Сервер пишет «Сборка не совпадает с сервером».** В папке игры лишний или изменённый мод или
ресурспак. Нажмите «Проверить файлы» в лаунчере и зайдите снова. Свои шейдеры ставить можно.

**Куда лаунчер всё ставит.** В `%APPDATA%\MACE`. Ссылка «Папка игры» открывает папку со сборкой.
Удалить всё: удалить эту папку и сам `MACE.exe`.

**Лаунчер обновляется сам.** При запуске он сверяет свою версию со списком сборки и при выходе новой
скачивает её и перезапускается.

## Что в репозитории

| Папка | Что там |
|---|---|
| `launcher/` | исходный код лаунчера (C#, WPF, .NET 8) и его проверки, описание в `launcher/README.md` |
| `tools/` | скрипты, которые собирают список сборки и выкладывают её в релиз, описание в `tools/README.md` |

Файлы сборки лежат в релизе [`pack`](https://github.com/Glesooo/battlefield-modpack/releases/tag/pack):
моды, ганпаки, ресурспаки, шейдеры, архив конфигов, сам лаунчер и `manifest.json`, по которому лаунчер
проверяет каждый файл по SHA-256.

До октября 2026 сборка обновлялась через packwiz и апдейтер `BattlefieldUpdater`. Они убраны из
репозитория, их файлы остались в истории коммитов.
